# Contributing

1. Fork the repository and create a focused branch.
2. Keep changes small and explain the product/security reason.
3. Run `npm install`, `npm run lint`, `npm run typecheck`, `npm run test` and `npm run build` before opening a pull request.
4. Never commit secrets or service-role keys.
5. Do not add fabricated marketplace data, testimonials, ratings or performance claims.
6. Changes affecting Supabase must include the migration and update the API/security documentation.
